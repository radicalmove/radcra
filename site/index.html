RADCRA - Course Review App (BETA)

THIS EXTENSION IS FOR BETA TESTING

RADCRA lets authorised reviewers add comments, highlights, and review markers to configured Moodle course pages and embedded learning content.

Downloads

  • Web Store upload package
    For the private Chrome Web Store beta. Chrome manages updates after installation.
  • Private pilot ZIP
    For approved developers using Chrome or Edge Developer mode and Load unpacked.

The GitHub Releases page contains checksums, release notes, and previous builds.

Install and update

Web Store testers install the private item from Chrome and receive browser-managed updates. Pilot testers extract the ZIP outside the repository, choose its moodle-review-extension/ folder with Load unpacked, then replace that folder and press Reload for a later build. The extension never downloads or executes replacement code.

Privacy and support
