Sphere - Course Review App (BETA)

THIS EXTENSION IS FOR BETA TESTING

Sphere lets authorised reviewers add comments, highlights, and review markers to configured Moodle course pages and embedded learning content.

Install Sphere

Add Sphere from the Chrome Web Store. Then open the Moodle course link your course team gave you. The listing is unlisted; installing does not grant course access.

Use the step-by-step installation and course-access guide. Sphere supports configured courses on UCO Moodle and LEARN; each course needs to be enabled by its team.

Developer and pilot builds

Ordinary reviewers should use the Chrome Web Store link above. Unpacked pilot builds are supplied privately by the release operator; do not install an old ZIP or run two copies of Sphere.

Install and update

Chrome updates Store installs automatically. Unpacked pilot installs update manually. See how to request access or switch from an older install.

Privacy and support

Read the privacy policy. For access, data, or release questions, use support.

Legacy pilot metadata: latest.json. Chrome manages Store updates separately.
