Install Sphere in Chrome

Use the official Store copy in the Chrome profile you use for your courses. No ZIP or Developer mode is needed.

Open the official Chrome Store listingOpen the full setup guide

Installation is the first step

  1. Open the listing in Chrome on your computer.

    Choose Add to Chrome, review its requested permissions and confirm Add extension if you agree.

  2. Open your course and refresh.

    Sign in to Moodle/LEARN normally. Read Sphere’s first-use notice and Continue only if you agree. Look for its panel or compact strip at the bottom right.

  3. Connect to the course.

    New reviewers use Request access. Already-approved reviewers use ordinary Sign in. Follow the email and Check access steps.

    You are ready when: Sphere shows Connected with the expected course role. Installing it alone does not grant review access.

Replacing an old pilot?

Keep the old copy disabled while you verify the Store copy. Once the Store version connects and loads the expected comments, remove only the old manually loaded Sphere/RADCRA extension.

Follow the replacement checklist →

Cannot install or see it?

Check the Chrome profile, extension enablement, site access and any work-managed browser restrictions.

Open troubleshooting →

Updates and private builds

Chrome updates the Store copy automatically. If an update asks for an additional site permission, review it before re-enabling Sphere, then refresh the course.

Private unpacked builds are for explicitly approved pilots and are supplied by the release operator. They do not update automatically through the Store.

Legacy pilot metadata: latest.json. This is not a reviewer installation package.
