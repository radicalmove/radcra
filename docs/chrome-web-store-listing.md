# Chrome Web Store listing

**Name:** RADCRA — Course Review (BETA)

**Description:** THIS EXTENSION IS FOR BETA TESTING. RADCRA helps authorised course reviewers inspect Moodle and embedded course content, place comments, and navigate review feedback.

**Privacy policy:** https://radicalmove.github.io/Beta-testing-app/privacy/

**Support:** https://github.com/radicalmove/Beta-testing-app/issues

**Single purpose:** course review. Reviewers can place text/area markers, add replies/status changes, and navigate comments in Moodle and embedded Rise/SCORM content.

**Data practices:** the extension handles reviewer/session details, Moodle/course/page URLs and titles, selected text, comments/replies/status, optional screenshots, and operational diagnostics. Data is sent over HTTPS only to the configured review service and the Moodle page already being reviewed; it is not sold or used for advertising. See the public policy for retention/deletion and the Chrome Web Store Limited Use statement.

Permissions are used only for the Moodle review pages, the configured review service, local storage/session state, and read-only release metadata at `https://radicalmove.github.io/Beta-testing-app/latest.json`. The extension does not execute remote code or download/install updates. Distribution is restricted to trusted private-beta testers.
