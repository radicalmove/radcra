RADCRA — Course Review (BETA) privacy policy

Effective date: 14 August 2026 · Policy version: 2026-08-14

RADCRA is a private beta Chrome extension for authorised course reviewers. The data controller is Richard Davies (University of Canterbury), richard.davies@canterbury.ac.nz. Support and data questions can be raised at the project issue tracker.

Data the extension handles

  • authentication and reviewer-session information, including short-lived tokens, device/reconnect credentials, reviewer name, email, role and approval state;
  • Moodle and course information, including course, activity, page and SCORM URLs, identifiers, titles and current page location;
  • selected text, visual anchors, comments, replies, status changes, timestamps and optional screenshots or attachments;
  • operational diagnostics such as browser/build version, navigation state and error logs.

Purpose, sharing and security

We use this information to authenticate an authorised reviewer, connect to the selected course, display and navigate comments, save feedback, reconcile status changes and improve the beta. Optional screenshots and attachments are sent only when requested. Data is sent only to the configured review service and the Moodle site already in use; it is not sold or used for advertising. Network traffic uses HTTPS, tokens stay in Chrome session storage where possible, and the extension does not execute remote code.

Retention and deletion

Comments and course data remain in the review service until deleted by the course owner or an authorised reviewer. Signing out removes local session and device credentials. Declining the policy leaves the reviewer signed out and prevents course data access. Contact Richard Davies or use the issue tracker to request deletion or ask about retention.

Chrome Web Store Limited Use disclosure

RADCRA’s use of data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. The extension uses user data only to provide or improve its single purpose—course review—and does not transfer, sell, or use that data for unrelated purposes such as advertising or creditworthiness. Human access is limited to people who need it to operate, support or improve the authorised beta review service.

A new policy version requires a fresh acknowledgement before the extension can access course or review data.
