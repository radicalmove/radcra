# Chrome Web Store listing

**Name:** RADCRA — Course Review (BETA)

**Description:** THIS EXTENSION IS FOR BETA TESTING. RADCRA helps authorised course reviewers inspect Moodle and embedded course content, place comments, and navigate review feedback.

**Privacy policy:** https://radicalmove.github.io/Beta-testing-app/privacy/

**Support:** https://github.com/radicalmove/Beta-testing-app/issues

Permissions are used only for the Moodle review pages, the configured review service, local storage/session state, and read-only release metadata at `https://radicalmove.github.io/Beta-testing-app/latest.json`. The extension does not execute remote code or download/install updates.
