Clear feedback, right where it belongs.

Sphere helps approved reviewers add comments, highlights and markers to configured courses on UCO Moodle and LEARN. It does not change Moodle content.

Install SphereRead the setup guide

THIS EXTENSION IS FOR BETA TESTING

One installation. Approval for each course.

Install the official Chrome Store copy, open your course, then connect using your approved Sphere account. New reviewers request a course role and wait for administrator approval before confirming their email.

Installing the extension does not give you access to Moodle or approve you for a Sphere course. Your course team supplies the course link and access arrangements.

Updates and developer builds

Chrome manages updates for the Store copy. Unpacked pilots update manually and are supplied privately by the release operator. Ordinary reviewers should not install a ZIP or run both copies.

Legacy pilot metadata is at latest.json; it is separate from Chrome Store updates.
