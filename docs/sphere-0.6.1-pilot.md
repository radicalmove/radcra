# Sphere 0.6.1 pilot

Load the unpacked 0.6.1 folder in Chrome and refresh Moodle. Keep the 0.6.0 demo folder for rollback. The new **Full course review** button opens history, original and verified current quotes, a checklist for the current review session, and CSV/JSON exports. Export the checklist to keep a copy. Creation dates need the updated review API; older servers continue to work and show “Date unavailable”.

On an SME quiz preview, open Sphere’s Chrome toolbar menu once to grant temporary tab access, then save a comment. Automatic capture is selected by default in the preview composer and can be turned off there. Capture applies to the visible preview only; a failed capture does not stop the comment from saving. Start from a test quiz before reviewing live material.

Use **Pause Sphere** in the Chrome toolbar menu to stop the overlay in this Chrome profile, and **Resume Sphere** to restore it. Use the Resolved filter to see resolved markers. When the original quote no longer has a reliable location, the comment and original quote remain in the review workspace.

Publish the updated privacy notice alongside the release. The new extension uses a backwards-compatible request for creation timestamps; deploy the updated review service to populate them.
