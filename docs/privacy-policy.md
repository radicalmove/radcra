# Sphere - Course Review App (BETA) privacy policy

**Effective date / policy version:** 7 November 2026 / 2026-11-07

**Public copy:** https://radicalmove.github.io/sphere/privacy/

**Contact:** rcadavies@gmail.com · **Support:** https://radicalmove.github.io/sphere/support/

Sphere is a private beta for authorised course-team reviewers.

## Data handled and purpose

Sphere handles reviewer name, email, role, and approval status; authentication, session, reconnect, and device credentials; course/page URLs and activity/SCORM identifiers, titles, and current location; comments, replies, statuses, timestamps, selected text, visual anchors, and optional screenshots and attachments submitted only at the reviewer's request; and browser/build, navigation, reliability, and error diagnostics. Local storage contains only the minimum session/access state, panel preferences, update state and policy-version acknowledgement.

This data is used only to authenticate reviewers and let them record, discuss, navigate to and resolve contextual feedback, support the beta, secure it, and improve that single purpose. Attachments are selected by the reviewer. When saving a staff Moodle quiz-preview comment, Sphere can include a screenshot automatically if the capture option displayed in the composer is checked and the reviewer has granted temporary tab access through Sphere’s Chrome controls. The option can be unchecked before saving. It does not capture learner attempts or take background screenshots.

Course-access and review notifications are sent through the operator’s Gmail account. These emails can include the reviewer’s name and email, course/page location, comment text, and a course link, as appropriate to the recipient’s approved role. Google processes the notification messages to deliver them. The isolated fictional Store-review demo does not send email.

Data travels over HTTPS only to the configured review service and the Moodle/content sites the reviewer opens. Authorised course-team members may read course-review content. Service operator staff do not routinely read it and may access specific data only on explicit user request about that data, for security or abuse, or legal obligation. Internal operational or improvement use is limited to aggregated and anonymised data. Data is not sold, brokered, used for advertising, creditworthiness, or lending, or transferred for unrelated purposes. Sphere executes no remote code.

GitHub Pages receives ordinary request metadata: IP address, user agent, request time, and requested path. Sphere sends it no Moodle content, review content, credentials, or tokens. `latest.json` contains version/release metadata only.

Review records remain until deleted under the course service controls or an authorised deletion request. Sign-out removes local session/device credentials. Decline remains fail-closed: the reviewer stays signed out and no course data is accessed. Retention/deletion questions may be sent to rcadavies@gmail.com without including sensitive course data.

## Chrome Web Store Limited Use

Sphere’s use of data complies with the Chrome Web Store User Data Policy, including the **Limited Use** requirements. Use, transfers and human access are limited to providing or improving the disclosed single course-review purpose and the permitted support, security and legal exceptions. A changed policy version requires fresh acknowledgement before course access.
