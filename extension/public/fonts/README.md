# Poppins font assets

These four files are the static Poppins regular, medium, semibold and bold faces
used by the Sphere extension UI:

- Source: [Google Fonts Poppins](https://github.com/google/fonts/tree/main/ofl/poppins)
- Retrieved from the Google Fonts repository on 2026-08-20.
- License: SIL Open Font License 1.1, as published in `ofl/poppins/OFL.txt`.

The font files are packaged locally so the extension does not request remote
assets at runtime. The complete SIL OFL text is available in the upstream
repository linked above.
